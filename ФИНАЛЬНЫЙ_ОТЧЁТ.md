### 1. Анализ и Исправление Мерцания ✅

#### Проблема #1: Дублирующий Код
**Симптомы:** Мерцание при открытии любых файлов, двойное изображение.

**Причина:** В `ReaderScreenContent` функции `PagedReaderWithGestures` и `WebtoonReader` вызывались **ДВА РАЗА**, создавая двойной рендеринг.

**Решение:** Удалён первый дублирующий блок (строки 350-387).

**Файл:** `android/feature-reader/src/main/java/com/example/feature/reader/ui/ReaderScreen.kt`

#### Проблема #2: Мерцание при Переключении Режимов
**Симптомы:** Мерцание и наложение изображений при переключении Page ↔ Webtoon.

**Причина:** Кэш не очищался при смене режима, старые страницы накладывались на новые.

**Решение:** Обновлена функция `setReadingMode()` с полной очисткой кэша и перезагрузкой книги.

**Файл:** `android/feature-reader/src/main/java/com/example/feature/reader/ui/ReaderViewModel.kt`

```kotlin
fun setReadingMode(mode: ReadingMode) {
    if (mode != _uiState.value.readingMode) {
        viewModelScope.launch {
            // 1. Обновляем настройки
            settingsRepository.setReadingMode(...)
            
            // 2. Сбрасываем кэш
            bitmapCache.clearCache()
            
            // 3. Сбрасываем UI State
            _uiState.update { 
                it.copy(
                    readingMode = mode,
                    bitmaps = emptyMap(),
                    currentPageBitmap = null,
                    currentPageIndex = 0,
                    pageCount = 0,
                    error = null,
                    isLoading = true
                )
            }
            
            // 4. Перезагружаем книгу
            val currentUri = _uiState.value.currentComicUri
            if (!currentUri.isNullOrEmpty()) {
                openBook(Uri.parse(currentUri))
            }
            
            // 5. Analytics
            analyticsHelper.track(...)
        }
    }
}
```
