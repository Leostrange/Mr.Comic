# Mr.Comic — Тасклист (MVP)

Легенда приоритетов: 
- P0 — критично для MVP, 
- P1 — важно сразу после P0, 
- P2 — можно параллелить/после стабилизации.

Модули (ориентиры): `app/`, `core-ui/`, `core-data/`, `core-domain/`, `core-model/`, `core-common/`, `core-database/`, `feature-*`, `data/*`.

---

## Тема 1. Архитектура и инфраструктура (app, core/*)

### Блок P0: Базовая архитектура
- Настроить модули: `app`, `core-ui`, `core-data`, `core-domain`, `core-model`, `core-common`, `core-database`, `feature-*`.
- Подключить Hilt, Navigation Compose, Room, DataStore, Coroutines/Flow.
- Развести слои MVVM + Clean Architecture (интерфейсы репозиториев, use cases).
- Результат: проект собирается, пустой стартовый экран.
- Зависимости: —

### Блок P1: Навигация и окна
- NavGraph, поддержка BottomNav/NavigationRail по `WindowSizeClass`.
- Единый helper для `WindowInsets`/immersive режима.
- Результат: бесшовное переключение экранов.
- Зависимости: базовая архитектура.

### Блок P1: Room/FTS
- Инициализация БД Room, FTS таблицы для поиска, миграции.
- Результат: FTS-запросы по тестовым данным работают.
- Зависимости: `core-database`.

---

## Тема 2. Библиотека и импорт (feature-library, data/comic-formats)

### Блок P0: Импорт форматов CBZ/CBR/PDF
- CBZ: извлечение изображений из ZIP.
- CBR: чтение RAR (библиотека, обработка паролей/ошибок).
- PDF: рендер страниц через `PdfRenderer` с пейджингом.
- Обработка ошибок: try/catch для битых архивов, уведомления вместо крэшей.
- Критерии: импорт ≤ 5 сек/комикс; корректный подсчёт страниц; извлечение обложки; отсутствие падений.
- Зависимости: Room, репозиторий комиксов.

### Блок P1: Сканер и индексация
- Сканирование папок с debounce; инкрементальные обновления.
- Индексация метаданных (ComicInfo.xml, EXIF), генерация превью.
- Результат: библиотека обновляется без лагов, превью корректны.
- Зависимости: импорт.

### Блок P1: Поиск/сортировка/фильтры
- Поиск (debounce 300 мс) по названию/автору/тегам (FTS).
- Сортировки: дата, название, автор, прогресс; базовые фильтры.
- Критерии: ответ < 150 мс на 5k записей.
- Зависимости: Room FTS.

### Блок P2: Доп. устойчивость
- Обработка частично повреждённых архивов/PDF (fallback страниц).
- Логи целостности и проблемных файлов.

## Тема 3. Читалка (feature-reader, core-ui)

### Блок P0: Рендер и жесты
- `HorizontalPager`; `ComicPage` с `transformable` (зум/панорамирование).
- Режимы: 1 страница, 2 страницы, вертикальная лента/webtoon.
- Критерии: 60 FPS; задержка отрисовки < 300 мс.
- Багфикс: при активном зуме блокировать горизонтальный свайп; dead-zone у краёв.
- Зависимости: импорт страниц.

### Блок P1: Навигация и прогресс
- Панель миниатюр, быстрый ползунок; сохранение прогресса (Room/DataStore).
- Автоскрытие UI, полноэкранный режим через Insets helper.
- Результат: возобновление чтения с нужной страницы, плавная навигация.

### Блок P1: Качество изображения
- ContentScale, EXIF-ориентация, anti-alias для текста/линий.
- Coil placeholders/transition для устранения «мигания».
- Результат: корректная ориентация, без мерцаний.

## Тема 4. OCR и переводы (feature-ocr)

### Блок P0: Базовый OCR (ML Kit)
- UI выделения области (overlay), live preview, вывод текста.
- История распознаваний (Room таблица).
- Критерии: точность ≥ 85% для печатного EN/JA/RU.
- Зависимости: готовый рендер страниц в читалке.

### Блок P1: Онлайн‑переводы
- Интеграция Google Translate / DeepL; ключи — Keystore.
- Оверлей перевода поверх страницы; редактор результатов; сохранение.
- Критерии: время получения перевода < 1 с (при нормальной сети).

### Блок P2: Продвинутые движки/офлайн
- Переключение на Tesseract/Paddle/EasyOCR; локальные модели HF.
- Кеширование переводов; выбор движка в настройках.

## Спринтовое разбиение (пример; 4 спринта × 2 недели)

- **Спринт 1 (P0):** Архитектура, импорт CBZ/CBR/PDF, базовая библиотека, навигация, темы MD3, cache/предзагрузка.

## Definition of Done (DoD) — ключевые блоки

- **Импорт:** ≥ 99% успешности валидных файлов; отсутствие крэшей на битых.
- **Читалка:** 60 FPS; без «миганий»; прогресс восстанавливается после перезапуска.
- **OCR/переводы:** OCR ≥ 85% (печатный); перевод < 1 с онлайн; редактирование и сохранение результатов.
- **Безопасность:** ключи не в коде; HTTPS защищён; сессии шифрованы.
- **Тесты/перф:** ключевые UI/интеграции зелёные; перф-метрики выдержаны.
