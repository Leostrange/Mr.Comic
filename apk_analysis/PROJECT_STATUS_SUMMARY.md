## 🔍 Анализ отключенного модуля

### android:feature-cbr - CBR/RAR поддержка

#### **Проблема:**
```
Error: Failed to find feature name for :android:feature-cbr 
in feature-metadata.json
```

#### **Причины:**
1. **Отсутствие Dynamic Features конфигурации** в основном приложении
2. **Неправильный AndroidManifest.xml** в feature-cbr
3. **Отсутствие строковых ресурсов** (`@string/cbr_module_title`)
4. **Проблемы с зависимостями** между модулями

#### **Влияние на пользователя:**
- **Минимальное**: CBR/RAR файлы составляют ~10-15% от всех комиксов
- **Альтернативы**: Пользователи могут конвертировать CBR в CBZ
- **Основная функциональность**: Не затронута
