# План функционального тестирования

## Цель тестирования
Проверить корректность работы интегрированных компонентов:
- Видео-сплэшскрин
- Система множественных иконок
- Совместимость с различными версиями Android

## 1. Тестирование видео-сплэшскрина

### 1.1 Тест воспроизведения видео
**Цель**: Убедиться, что видео-сплэш корректно воспроизводится

**Шаги**:
1. Запустить приложение
2. Проверить, что видео начинает воспроизводиться
3. Дождаться завершения видео
4. Убедиться в переходе к основному экрану

**Ожидаемый результат**: 
- Видео воспроизводится без ошибок
- Переход к MainActivity происходит автоматически

### 1.2 Тест fallback механизма
**Цель**: Проверить работу fallback при ошибках видео

**Шаги**:
1. Временно повредить видео-файл или удалить его
2. Запустить приложение
3. Проверить показ статического сплэша

**Ожидаемый результат**: 
- При ошибке видео показывается статический сплэш
- Приложение не крашится

### 1.3 Тест на разных версиях Android
**Цель**: Проверить совместимость с Android 12+ и более старыми версиями

**Устройства для тестирования**:
- Android 12+ (API 31+): Современный SplashScreen API
- Android 5.0-11 (API 21-30): Кастомный видео-сплэш

## 2. Тестирование системы иконок

### 2.1 Тест смены иконок
**Цель**: Проверить корректность смены иконок приложения

**Шаги**:
1. Открыть настройки приложения
2. Перейти в раздел "App Icon"
3. Выбрать альтернативную иконку
4. Проверить изменение иконки в лаунчере

**Ожидаемый результат**: 
- UI показывает все доступные иконки
- Выбранная иконка применяется немедленно
- Иконка в лаунчере изменяется

### 2.2 Тест сохранения выбора
**Цель**: Убедиться, что выбор иконки сохраняется

**Шаги**:
1. Выбрать альтернативную иконку
2. Перезапустить приложение
3. Проверить, что выбранная иконка остается активной

**Ожидаемый результат**: 
- Выбор иконки сохраняется в SharedPreferences
- После перезапуска активна та же иконка

### 2.3 Тест activity-aliases
**Цель**: Проверить корректность настройки activity-aliases

**Шаги**:
1. Проверить AndroidManifest.xml на наличие всех aliases
2. Убедиться, что только одна иконка активна одновременно
3. Проверить правильность intent-filter

## 3. Тестирование производительности

### 3.1 Тест времени запуска
**Цель**: Измерить влияние видео-сплэша на время запуска

**Метрики**:
- Время от запуска до показа видео
- Время воспроизведения видео
- Общее время до показа основного экрана

**Целевые значения**:
- Инициализация видео: < 500ms
- Общее время сплэша: 2-3 секунды

### 3.2 Тест использования памяти
**Цель**: Проверить потребление памяти при воспроизведении видео

**Метрики**:
- Потребление памяти до запуска видео
- Пиковое потребление во время воспроизведения
- Освобождение памяти после завершения

## 6. Результаты тестирования

### Статус выполнения:
- ✅ Unit тесты созданы и готовы к запуску
- ✅ Инструментальные тесты созданы
- ✅ Архитектура тестирования настроена
- ⏳ Ручное тестирование требует сборки APK
- ⏳ Автоматизированные UI тесты требуют доработки

### Ограничения:
- Полное тестирование заблокировано ошибками компиляции в core-reader
- Основная функциональность (сплэш + иконки) готова к тестированию
- Тесты можно запускать на изолированных компонентах

## Заключение

1. Исправить ошибки компиляции для создания APK
2. Провести ручное тестирование на реальных устройствах
