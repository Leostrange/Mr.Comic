Проект уже содержит структуру для множественных иконок:
- `ic_launcher.png` - основная иконка
- `ic_launcher_round.png` - круглая иконка

- `ic_launcher_alt2.png` - альтернативная иконка 2
- `ic_launcher_alt3.png` - альтернативная иконка 3

Иконки присутствуют во всех необходимых разрешениях:
- mipmap-mdpi/
- mipmap-hdpi/
- mipmap-xhdpi/
- mipmap-xxhdpi/
- mipmap-xxxhdpi/

#### Видео ресурсы (raw)
- `splash_video.mp4` - видео для сплэш-экрана
- `splash_video.gif` - GIF версия (fallback)
- `splash_video_preview.gif` - превью версия

### Архитектура приложения

#### Основные компоненты
- **ComicApplication** - Application класс
- **MainActivity** - главная активность
- **Navigation** - система навигации
- **DI** - Dependency Injection (Hilt)
- **ViewModels** - архитектура MVVM

#### Модульная структура
- **app** - основной модуль приложения
- **core-reader** - модуль для чтения комиксов
- **feature-cbr** - модуль для CBR файлов
- **shared** - общие компоненты
