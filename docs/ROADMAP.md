# ROADMAP Mr.Comic - ОБЩИЙ ПЛАН РАЗВИТИЯ

## 🎯 ЦЕЛЬ ПРОЕКТА
Создание современного приложения для чтения комиксов с поддержкой различных форматов (CBZ, CBR, PDF) и продвинутыми функциями чтения.

---

## 📊 ТЕКУЩИЙ СТАТУС (v1.0.12)

### ✅ ВЫПОЛНЕНО (44% - 11/25 задач):
1. **Стабилизация панели инструментов** - предсказуемое появление/скрытие
2. **Сохранение прогресса чтения** - исправлена потеря позиции
3. **Блокировка листания при зуме** - исправлен конфликт жестов
4. **Улучшение поддержки CBR** - надежная библиотека и обработка ошибок
5. **Управление памятью** - предотвращены утечки и перегрузка
6. **Навигация по страницам** - быстрый переход с миниатюрами
7. **Единообразный полноэкранный режим** - решены проблемы с системными жестами
8. **Double-Tap Zoom** - поддержка увеличения двойным тапом
9. **Тап-зоны для навигации** - невидимые области для листания
10. **Слайдер яркости** - реальное изменение яркости экрана
11. **Критическое исправление LruCache** - устранена ошибка inconsistent results

### ⏳ В ОЖИДАНИИ (56% - 14/25 задач):
- Оптимизация рендеринга PDF
- Обработка больших CBZ и ошибок распаковки
- Двухстраничный режим в ландшафте
- Непрерывная прокрутка вебтуна
- Локальный бэкап
- И другие...

## 📱 ПОДДЕРЖИВАЕМЫЕ ПЛАТФОРМЫ

### Android
- **Минимальная версия:** API 21 (Android 5.0)
- **Рекомендуемая:** API 33+ (Android 13+)
- **Архитектура:** Multi-module (app, core, feature)

### Форматы файлов
- **CBZ** - ZIP архивы с изображениями
- **CBR** - RAR архивы с изображениями  
- **PDF** - Документы PDF
- **Изображения** - JPG, PNG, WebP
