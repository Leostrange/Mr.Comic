## Введение

**Mr.Comic** — это современное мобильное приложение для чтения комиксов, манги и графических новелл на устройствах Android. Приложение поддерживает популярные форматы (CBR, CBZ, PDF) и предоставляет удобные инструменты для организации коллекции.

## Установка

### Системные требования
- **ОС**: Android 7.0 (Nougat) или выше (API 24+)
- **Свободное место**: ~20 МБ для приложения + место для комиксов

### Инструкция по установке
1. Скачайте установочный файл `.apk` из официального источника (GitHub Releases).
2. Запустите файл на вашем устройстве.
3. Если потребуется, разрешите установку из неизвестных источников в настройках безопасности Android.
4. После установки нажмите "Открыть".

### Первоначальная настройка
При первом запуске приложение запросит разрешение на **доступ к хранилищу файлов**. Это необходимо для того, чтобы Mr.Comic мог найти и отобразить ваши комиксы. Нажмите "Разрешить".

## Библиотека комиксов

После предоставления разрешений приложение автоматически сканирует устройство на наличие поддерживаемых файлов.

- **Обновление библиотеки**: Свайпните вниз по списку, чтобы обновить библиотеку.
- **Поиск**: Используйте иконку лупы для поиска по названию.
- **Сортировка**: Доступна сортировка по названию, дате добавления и дате открытия.

## Режим чтения

Нажмите на обложку комикса, чтобы открыть его.

### Управление и жесты
- **Листание страниц**:
  - Нажмите на **правую часть экрана** для перехода вперед.
  - Нажмите на **левую часть экрана** для перехода назад.
  - Также поддерживаются свайпы влево/вправо.
- **Меню и навигация**:
  - Нажмите в **центр экрана**, чтобы показать/скрыть панели инструментов.
  - Используйте слайдер внизу для быстрого перехода к нужной странице.
- **Масштабирование**:
  - Используйте жест "щипок" (pinch-to-zoom) для увеличения изображения.
  - Двойное касание (double-tap) для быстрого увеличения/уменьшения.

## Дополнительные функции

### OCR и Перевод
Приложение поддерживает распознавание текста на страницах комиксов.
1. В режиме чтения откройте меню (тап в центр).
2. Выберите инструмент OCR/Перевод (если доступен в вашей версии).
3. Выделите область с текстом для распознавания или перевода.

### Темы оформления
Приложение поддерживает светлую и темную темы, а также адаптацию под системные цвета (Material You) на поддерживаемых устройствах.

## Настройки

В меню настроек вы можете изменить:
- **Тему интерфейса**: Светлая / Темная / Системная.
- **Настройки чтения**: Ориентация экрана, режим масштабирования.
- **Управление кэшем**: Очистка временных файлов для освобождения памяти.

## Часто задаваемые вопросы

**В: Какие форматы поддерживаются?**
О: Основные форматы — CBR (RAR) и CBZ (ZIP). Также поддерживаются PDF и обычные папки с изображениями.

**В: Где скачать комиксы?**
О: Приложение является "читалкой" и не предоставляет контент. Вы можете загрузить свои комиксы в память устройства.

**В: Приложение тормозит на больших файлах.**
О: Мы работаем над оптимизацией. Попробуйте очистить кэш в настройках или перезапустить приложение.
