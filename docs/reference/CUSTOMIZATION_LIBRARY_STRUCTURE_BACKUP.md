# Backup: Кастомизация и Библиотека

Дата среза: 2026-03-23

## Назначение

Этот файл фиксирует текущую рабочую структуру настроек для разделов:

- `Кастомизация`
- `Библиотека`

Нужен как быстрый reference-срез перед дальнейшими переработками UI.

## Источник кода

- `android/feature-settings/src/main/java/com/example/feature/settings/ui/SettingsScreen.kt`
- `android/feature-settings/src/main/java/com/example/feature/settings/ui/SettingsViewModel.kt`
- `android/core-data/src/main/java/com/example/core/data/preferences/PreferencesKeys.kt`

## Кастомизация

Текущая структура:

- `Основное`
  - язык приложения
  - предпросмотр
  - иконки приложения
- `Тема`
  - пресеты темы
  - режим темы
  - dynamic color
  - AMOLED
  - сохранённые темы приложения
- `Масштаб`
  - масштаб шрифта
  - плотность интерфейса
  - скругление интерфейса
- `Цвета`
  - primary
  - secondary
  - background
  - surfaces/cards
  - прозрачность поверхностей
- `Дополнительно`
  - звуки UI
  - маскот
  - discovery prompts

## Библиотека

Текущая структура:

- `Вид`
  - grid/list
  - колонки
  - размер плитки
  - положение полки recent
- `Карточки`
  - плотность карточек
  - масштаб обложек
  - форма миниатюр
  - стиль графических обложек
  - прогресс на карточках
  - подписи на обложках
  - тень карточек
  - масштаб заголовка
  - количество строк заголовка
  - контур карточки
  - скругление карточек
  - плотность плашки заголовка
- `Полки и фон`
  - стиль фона
  - сила фонового акцента
  - пользовательское изображение
  - blur
  - veil
  - прозрачность меню и панелей
  - стиль полок
  - глубина полок
  - сохранённые темы библиотеки
- `Сортировка`
  - сортировка по умолчанию
  - группировка библиотеки

## Что принципиально возвращено

- `Theme Studio` больше не является обязательной точкой входа.
- `Кастомизация` и `Библиотека` снова открываются как прямые рабочие разделы.
- Сохранённые темы:
  - темы приложения живут внутри `Кастомизация -> Тема`
  - темы библиотеки живут внутри `Библиотека -> Полки и фон`
