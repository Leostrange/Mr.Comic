# Reader Regression Checklist

## Pages Mode
- [ ] Открыть CBZ с 500+ страницами; убедиться, что миниатюры загружаются полностью (нет вечных индикаторов).
- [ ] Проверить переходы по миниатюрам: активная страница подсвечивается, переход мгновенный.
- [ ] Переключить несколько страниц подряд кнопками и жестами; убедиться в отсутствии пропусков страниц.
- [ ] Настроить яркость слайдером: плавное изменение без рывков, значение фиксируется после закрытия панели.
- [ ] Проверить полноэкранное изображение на 100 % зуме: отсутствие размытия/блюра, чтение мелкого текста.

## Webtoon Mode
- [ ] Проверить загрузку и плавный скролл для длинного Webtoon (100+ секций).
- [ ] Клик по миниатюре прокручивает список к целевой секции; активная секция подсвечена.
- [ ] Измерить производительность: отсутствуют рывки, FPS не проседает ниже 45 на тестовом устройстве.
- [ ] Слайдер яркости работает аналогично Pages Mode.

## Thumbnails & Preload
- [ ] Сменить файл и снова открыть панель миниатюр: удостовериться, что кэш очистился и перезаполнился актуальными данными.
- [ ] Проверить лог `PagePreloader`: диапазоны предзагрузки соответствуют текущей странице.

## Panels & Gestures
- [ ] Открыть верхнюю/правую панели и тапнуть по фону: панели закрываются.
- [ ] Жесты листания блокируются, когда панели открыты.
- [ ] При тапе внутри панели события не закрывают панель.

## PDF
- [ ] Открыть 10 PDF (размер до 120 MB, различные DPI): страницы рендерятся без падений.
- [ ] Проверить страницу №12 в каждом файле (исторически проблемная): рендер без пустых кадров.
- [ ] Сравнить качество PDF-страницы (3200 dpi) с оригиналом: отсутствие деградации, чёткий текст.

## CBR / CBZ / Папки
- [ ] Открыть CBR с вложенными директориями и именами `1.jpg`, `10.jpg`, `2.jpg`: порядок страниц корректный.
- [ ] Проверить CBR, сконвертированный из RAR4 и RAR5: приложение сообщает об ошибке формата RAR5.
- [ ] Листать 100+ страниц подряд: нет повторов или пропусков.

## Debug Overlay
- [ ] В debug-сборке отображается оверлей: отображает страницу, разрешение, время рендера, статистику кэша.
- [ ] Значения обновляются при переключении страниц, `renderTimeMs` < 120 мс для CBZ/PDF среднего размера.

## Автоматические проверки
- [ ] Запустить юнит-тесты PDF-ридера: `./gradlew :android:core-reader:test`.
- [ ] Выполнить `PdfReaderTest.testAllReaders()` и `testFactoryWithFallback()` на выборке из 3 PDF (малый, средний, большой).
- [ ] (План) Добавить UI-тест для панели миниатюр (сценарий: открыть панель → перейти по миниатюре → проверить подсветку).

## Smoke Checklist (после фиксов)
- [ ] CBZ, CBR, PDF, папка с изображениями открываются и листаются.
- [ ] Переключение между режимами Pages/Webtoon не сбрасывает состояние.
- [ ] Настройки яркости и масштаба сохраняются между сессиями.
- [ ] Панели открываются/закрываются и не перекрывают жесты чтения.
- [ ] Приложение не падает при быстрой смене файлов из библиотеки.
