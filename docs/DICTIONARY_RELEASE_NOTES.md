# Mr.Comic Dictionary Modules v1.0.0

Дополнительные офлайн-словари для Mr.Comic. Это **не APK и не обновление приложения**.

## Как использовать

- Проще всего: **Настройки → Перевод и словари → Скачать**.
- Для ручной установки скачайте только нужный `dictionary_<lang>.dbpack`, затем выберите **Импорт** в приложении.
- Для проверки целостности используйте `SHA256SUMS.txt`.

## Языки

`en` English · `fr` Français · `it` Italiano · `ja` 日本語 · `ko` 한국어 · `pl` Polski · `pt` Português · `ru` Русский · `tr` Türkçe · `zh` 中文

Размер полного набора — около 752 MB, поэтому модули опубликованы раздельно. Устанавливать весь набор не требуется.

Источники, атрибуция и лицензии: [Dictionary Modules](https://github.com/Leostrange/Mr.Comic/blob/main/docs/DICTIONARY_MODULES.md).
