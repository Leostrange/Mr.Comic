# 🚀 Инструкция по сборке APK для Mr.Comic

## ⚠️ ВАЖНО: Проблема с Gradle в командной строке

На вашей системе возникает проблема с Gradle кэшем при сборке через командную строку. 
Это связано с антивирусом или правами доступа к файлам.

## ✅ РЕКОМЕНДУЕМЫЙ СПОСОБ: Android Studio

### Шаг 1: Откройте проект в Android Studio

1. Запустите **Android Studio**
2. Выберите `File > Open`
3. Найдите и откройте папку: `C:\Users\xmeta\projects\Mr.Comic`
4. Нажмите `OK`

### Шаг 2: Дождитесь индексации

- Android Studio начнет индексировать проект
- Это может занять **5-15 минут** при первом открытии
- Внизу экрана будет показан прогресс
- Дождитесь завершения всех процессов

### Шаг 3: Синхронизация Gradle

- Android Studio автоматически запустит синхронизацию Gradle
- Если появится предложение обновить плагины - согласитесь
- Дождитесь сообщения "Gradle sync finished"

### Шаг 4: Соберите APK

1. В меню выберите: `Build > Build Bundle(s) / APK(s) > Build APK(s)`
2. Дождитесь завершения сборки (5-10 минут)
3. Появится уведомление: "APK(s) generated successfully"
4. Нажмите `locate` в уведомлении

### Шаг 5: Найдите APK

APK будет находиться в:
```
android\app\build\outputs\apk\debug\app-debug.apk
```

## 📱 Установка APK на устройство

### Вариант A: Через USB

1. Подключите Android устройство к компьютеру
2. Включите "Отладку по USB" на устройстве
3. В Android Studio нажмите `Run > Run 'app'`
4. Выберите ваше устройство из списка

### Вариант B: Через файл

1. Скопируйте `app-debug.apk` на устройство
2. Откройте файл на устройстве
3. Разрешите установку из неизвестных источников
4. Установите приложение

## 🐛 Если возникли проблемы

### Проблема: Android Studio не открывается

**Решение**: Убедитесь, что установлена последняя версия Android Studio:
- Скачайте с: https://developer.android.com/studio
- Установите и запустите

### Проблема: Gradle sync failed

**Решение**: 
1. В Android Studio: `File > Invalidate Caches / Restart`
2. Выберите `Invalidate and Restart`
3. Дождитесь перезапуска и повторной синхронизации

### Проблема: Build failed с ошибками компиляции

**Решение**:
1. Проверьте, что установлен JDK 17 или выше
2. В Android Studio: `File > Project Structure > SDK Location`
3. Убедитесь, что JDK указан правильно

### Проблема: APK не устанавливается на устройство

**Решение**:
1. Проверьте, что на устройстве Android 8.0 или выше
2. Разрешите установку из неизвестных источников
3. Удалите старую версию приложения, если есть
