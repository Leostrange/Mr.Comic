## 🔧 Рекомендации для Release сборки

Для успешной сборки Release APK рекомендуется:

1. **Увеличить heap space** в `gradle.properties`:
```properties
org.gradle.jvmargs=-Xmx4g -XX:MaxMetaspaceSize=1g
```

2. **Использовать 64-bit JVM** для больших проектов

3. **Очистить кэш** перед сборкой:
```bash
.\gradlew.bat clean
.\gradlew.bat assembleRelease
```
