# Mr.Comic

![Mr.Comic Demo](media/demo.gif)

**Mr.Comic** - это мобильное Android-приложение для чтения комиксов в формате CBR/CBZ. Приложение предоставляет удобный интерфейс для просмотра, управления и организации коллекции комиксов.

## Возможности

- 📚 **Библиотека комиксов** - Организованное хранение и просмотр коллекции
- 👁️ **Чтение комиксов** - Удобный режим чтения с поддержкой жестов
- 🎨 **Темы оформления** - Настраиваемые темы интерфейса
- 🌐 **Локализация** - Поддержка русского и английского языков
- 🔍 **Поиск** - Быстрый поиск по названию и метаданным
- 📱 **Адаптивный дизайн** - Поддержка портретной и альбомной ориентации
- 🌓 **Темная тема** - Поддержка темной темы интерфейса
- 📖 **OCR и перевод** - Распознавание текста и перевод на другие языки
- 🔒 **Защита контента** - Поддержка защищенных файлов
- 🗂️ **Организация коллекции** - Группировка и сортировка по различным критериям

## Быстрый старт

### Системные требования

- **Android**: API 24+ (Android 7.0)
- **Размер**: ~15MB
- **Разрешения**: Доступ к хранилищу для чтения файлов комиксов

### Установка

1. Скачайте APK-файл из раздела [Releases](https://github.com/Leostrange/Mr.Comic/releases)
1. Установите приложение на устройство Android
1. Предоставьте разрешения на доступ к хранилищу
1. Добавьте комиксы в формате CBR/CBZ в папку приложения
1. Наслаждайтесь чтением!

## Разработка

### Требования к разработке

- **Android Studio**: Flamingo | 2022.2.1+
- **Kotlin**: 1.8.0+
- **Gradle**: 8.0+
- **JDK**: 17+

### Сборка проекта

```bash
# Клонирование репозитория
git clone https://github.com/Leostrange/Mr.Comic.git
cd Mr.Comic

# Сборка debug версии
./gradlew assembleDebug

# Установка на устройство
./gradlew installDebug
```

## Архитектура

Проект построен на основе **Clean Architecture** с разделением на слои:

- **Domain** - Бизнес-логика и use cases
- **Data** - Репозитории и источники данных
- **Presentation** - UI и ViewModels
- **Core** - Общие компоненты

## Технологии

- **Язык**: Kotlin
- **UI Framework**: Jetpack Compose
- **Architecture**: MVVM + Clean Architecture
- **Database**: Room
- **Dependency Injection**: Hilt
- **Async**: Coroutines + Flow
- **Navigation**: Compose Navigation
- **Testing**: JUnit + MockK
