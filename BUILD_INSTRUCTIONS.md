# Инструкция по сборке Mr.Comic APK

## ⚠️ КРИТИЧЕСКАЯ ПРОБЛЕМА: Gradle кэш постоянно повреждается

Если вы видите ошибку:
```
Could not read workspace metadata from C:\Users\...\gradle\caches\...
```

Это **системная проблема** с Gradle кэшем. Возможные причины:
- Антивирус блокирует создание файлов
- Проблемы с правами доступа к папке .gradle
- Поврежденная файловая система
- Конфликт с другими процессами

## 🔧 РЕШЕНИЯ (попробуйте по порядку):

### ✅ Решение 1: Сборка через Android Studio (РЕКОМЕНДУЕТСЯ)

Это самый надежный способ, который обходит проблемы с командной строкой:

1. Откройте **Android Studio**
2. Выберите `File > Open` и откройте папку проекта `Mr.Comic`
3. Дождитесь индексации проекта (может занять 5-10 минут)
4. Выберите `Build > Build Bundle(s) / APK(s) > Build APK(s)`
5. Дождитесь завершения сборки
6. APK будет в: `android\app\build\outputs\apk\debug\app-debug.apk`

### ⚙️ Решение 2: Отключить антивирус временно

Антивирус может блокировать создание файлов Gradle:

1. Временно отключите антивирус (Windows Defender или другой)
2. Удалите кэш: `rmdir /s /q %USERPROFILE%\.gradle`
3. Запустите сборку: `gradlew :android:app:assembleDebug`
4. После сборки включите антивирус обратно

### 🔐 Решение 3: Добавить исключение в антивирус

Добавьте папку `.gradle` в исключения антивируса:

**Windows Defender:**
1. Откройте `Параметры Windows > Обновление и безопасность > Безопасность Windows`
2. Выберите `Защита от вирусов и угроз > Управление настройками`
3. Прокрутите до `Исключения > Добавить или удалить исключения`
4. Добавьте папку: `C:\Users\<ваше_имя>\.gradle`

### 📁 Решение 4: Изменить расположение Gradle кэша

Создайте файл `gradle.properties` в корне проекта:

```properties
org.gradle.caching=false
org.gradle.daemon=false
org.gradle.parallel=false
```

Или переместите кэш в другое место:
```properties
gradle.user.home=C:/gradle-home
```

### 🛠️ Решение 5: Использовать Gradle Wrapper напрямую

Попробуйте собрать без использования кэша:

```cmd
gradlew.bat :android:app:assembleDebug --no-build-cache --no-daemon --offline
```

### 🔄 Решение 6: Переустановить Gradle

1. Удалите полностью папку `.gradle`:
   ```cmd
   rmdir /s /q %USERPROFILE%\.gradle
   ```

2. Удалите локальный wrapper:
   ```cmd
   rmdir /s /q .gradle
   ```

3. Скачайте Gradle заново:
   ```cmd
   gradlew.bat --version
   ```

## Проверка реализованных функций

После успешной сборки APK будет находиться в:
```
android\app\build\outputs\apk\debug\app-debug.apk
```

### Что можно протестировать (Задачи 1-7):

#### ✅ Задача 1: База данных
- Запустите приложение
- Данные должны сохраняться между запусками
- Проверьте, что настройки сохраняются

#### ✅ Задача 2: Репозитории
- Добавьте комикс
- Проверьте, что он появляется в библиотеке
- Удалите комикс - он должен исчезнуть из списка

#### ✅ Задача 3: Парсеры файлов
- Добавьте файлы разных форматов:
  - CBZ/ZIP файл
  - CBR/RAR файл
  - PDF файл
  - Папку с изображениями
- Проверьте, что все форматы распознаются

#### ✅ Задача 4: Индексация
- Добавьте директорию с комиксами
- Проверьте, что сканирование работает в фоне
- Проверьте прогресс сканирования
- Перезапустите приложение - сканирование должно восстановиться

#### ✅ Задача 5: Кэширование обложек
- Откройте библиотеку
- Обложки должны загружаться и кэшироваться
- Закройте и откройте приложение - обложки должны загружаться быстро из кэша

#### ✅ Задача 6: Экран библиотеки
- Проверьте три режима отображения:
  - Сетка (Grid)
  - Список (List)
  - Папки (Folder)
- Переключение должно быть мгновенным
- Проверьте отображение прогресса чтения
- Проверьте индикаторы закладок

#### ✅ Задача 7: Поиск и фильтрация
- Нажмите кнопку поиска
- Введите запрос - результаты должны появляться с задержкой 300ms
- Откройте фильтры
- Примените фильтры по:
  - Формату (CBZ, CBR, PDF)
  - Статусу чтения (Непрочитанные, Читаю, Прочитанные)
  - Дате добавления (Неделя, Месяц, Год)
  - Закладкам
- Проверьте сортировку (по названию, дате, размеру)

## Известные проблемы

### 1. Gradle кэш
**Проблема**: Поврежденный кэш Gradle  
**Решение**: Удалить `%USERPROFILE%\.gradle\caches` и пересобрать

### 2. Зависимости
Если возникают проблемы с зависимостями:
```powershell
.\gradlew --refresh-dependencies
```

### 3. KSP
Если KSP не генерирует код:
```powershell
.\gradlew clean
.\gradlew :android:core-model:kspDebugKotlin
.\gradlew :android:core-data:kspDebugKotlin
```

## Логи для отладки

Для просмотра логов во время работы приложения:
```powershell
adb logcat | Select-String "Comic|Library|Cover|Scan"
```

Или в Android Studio: View > Tool Windows > Logcat
