# ФИНАЛЬНОЕ ИСПРАВЛЕНИЕ МЕРЦАНИЯ

## Проблема
После первого исправления мерцание всё ещё оставалось при открытии файлов любого формата.

## Найденная Причина
**ДУБЛИРУЮЩИЙ КОД!** В `ReaderScreenContent` функция `PagedReaderWithGestures` и `WebtoonReader` вызывались **ДВА РАЗА**:

1. **Первый вызов** (строка ~350): Рендерился сразу после проверки `uiState.pageCount > 0`
2. **Второй вызов** (строка ~545): Рендерился внутри `Box` с `contentAlignment = Alignment.Center`

### Почему это вызывало мерцание?
Два одинаковых компонента рендерились друг поверх друга, создавая эффект "двойного изображения" и мерцания при любых изменениях состояния.

## Решение
Удалён первый дублирующий блок кода (строки 350-387), оставлен только второй вызов внутри Box.

### Код ДО исправления:
```kotlin
uiState.pageCount > 0 -> {
    // ПЕРВЫЙ ВЫЗОВ - ДУБЛИКАТ!
    when (uiState.readingMode) {
        ReadingMode.PAGE -> PagedReaderWithGestures(...)
        ReadingMode.WEBTOON -> OptimizedWebtoonLazyColumn(...)
    }
    
    // ... панели и индикаторы ...
    
    // ВТОРОЙ ВЫЗОВ - ТОТ ЖЕ САМЫЙ КОД!
    Box(...) {
        when (uiState.readingMode) {
            ReadingMode.PAGE -> PagedReaderWithGestures(...)
            ReadingMode.WEBTOON -> WebtoonReader(...)
        }
    }
}
```

### Код ПОСЛЕ исправления:
```kotlin
uiState.pageCount > 0 -> {
    // Удалён дублирующий блок!
    
    // ... панели и индикаторы ...
    
    // Только ОДИН вызов
    Box(...) {
        when (uiState.readingMode) {
            ReadingMode.PAGE -> PagedReaderWithGestures(...)
            ReadingMode.WEBTOON -> WebtoonReader(...)
        }
    }
}
```

### Исправление #2 (ФИНАЛЬНОЕ)

- Результат: Полное устранение мерцания
