## Ключевые исправления

### 1. ✅ Регулировка яркости

**Решение:** 
- Автоматическое переключение на режим `manual` при использовании слайдера
- Добавлен колбэк `onUpdateBrightnessMode`
- Работает во всех режимах чтения (Page и Webtoon)

### 2. ✅ Ошибка загрузки PDF

**Решение:**
- Специальная проверка для PDF файлов в `PagePreloader`
- Предзагрузка блокируется до полной загрузки текущей страницы
- Добавлены флаги готовности системы

### 3. ✅ Scale Mode и Zoom

**Решение:**
- `ContentScale.Fit` для правильного базового масштабирования
- Убрано ограничение на уменьшение масштаба
- Корректная работа всех режимов (Width/Height/Fit/Fill)

### 4. ✅ Webtoon улучшения

**Решение:**
- Отслеживание прокрутки для обновления индикатора
- Принудительная прокрутка к выбранной странице
- Добавлен параметр `onGoToPage`
