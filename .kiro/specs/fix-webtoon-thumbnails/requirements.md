# Requirements Document

## Introduction

Исправление критических багов в режиме чтения Webtoon и панели миниатюр. В текущей версии:
1. Webtoon режим возвращает на первую страницу при скролле
2. Миниатюры в правой боковой панели не подгружаются полностью

## Glossary

- **Reader System**: Система чтения комиксов в приложении
- **Webtoon Mode**: Режим вертикального скроллинга для чтения комиксов
- **Thumbnail Panel**: Панель с миниатюрами страниц для быстрой навигации
- **BitmapCache**: Кэш для хранения изображений страниц и миниатюр
- **LazyColumn**: Компонент Compose для отображения вертикального списка с ленивой загрузкой

## Requirements

### Requirement 1: Исправление Webtoon Режима

**User Story:** Как пользователь, я хочу плавно скроллить страницы в Webtoon режиме, чтобы читать комиксы без возврата на первую страницу

#### Acceptance Criteria

1. WHEN пользователь скроллит страницы в Webtoon режиме, THE Reader System SHALL сохранять текущую позицию скролла
2. WHEN пользователь просматривает страницу в Webtoon режиме, THE Reader System SHALL NOT вызывать onGoToPage для видимой страницы
3. WHEN пользователь скроллит в Webtoon режиме, THE Reader System SHALL обновлять индикатор текущей страницы без сброса позиции
4. WHILE пользователь находится в Webtoon режиме, THE Reader System SHALL использовать LazyColumn без принудительной прокрутки

### Requirement 2: Исправление Загрузки Миниатюр

**User Story:** Как пользователь, я хочу видеть все миниатюры страниц в панели навигации, чтобы быстро переходить к нужной странице

#### Acceptance Criteria

1. WHEN страница загружается, THE Reader System SHALL создавать миниатюру для этой страницы
2. WHEN миниатюра создаётся, THE Reader System SHALL сохранять её в BitmapCache
3. WHEN панель миниатюр открывается, THE Reader System SHALL отображать все доступные миниатюры
4. WHILE страница загружена, THE Reader System SHALL иметь соответствующую миниатюру в кэше
5. WHEN миниатюра отсутствует, THE Reader System SHALL создавать её из полноразмерной страницы

### Requirement 3: Интеграция с Избранным

**User Story:** Как пользователь, я хочу добавлять комиксы в избранное из левой панели, чтобы быстро находить их в библиотеке

#### Acceptance Criteria

1. WHEN пользователь нажимает кнопку избранного, THE Reader System SHALL сохранять статус избранного в базе данных
2. WHEN комикс добавлен в избранное, THE Reader System SHALL отображать красную иконку сердца
3. WHEN пользователь открывает библиотеку, THE Reader System SHALL показывать избранные комиксы
4. WHILE комикс в избранном, THE Reader System SHALL сохранять этот статус между сессиями
