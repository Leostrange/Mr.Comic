# План реализации Mr.Comic

## Этап 1: Базовая библиотека и файловая система

- [x] 1. Настройка моделей данных и базы данных





  - Создать Room entities для Comic, Folder, Bookmark, ReadingSession в core-model
  - Определить DAO интерфейсы с необходимыми запросами и индексами
  - Настроить ComicDatabase с миграциями
  - Создать DataStore preferences схему с ключами настроек
  - _Requirements: 1.1, 1.2, 12.4_

- [x] 2. Реализовать репозитории для работы с данными



  - Создать ComicRepository с методами CRUD и поиска
  - Реализовать FolderRepository для управления папками
  - Создать BookmarkRepository для закладок
  - Реализовать ReadingSessionRepository для сохранения прогресса
  - Добавить маппинг между слоями данных
  - _Requirements: 1.1, 1.3, 12.1, 12.2_

- [x] 3. Создать парсеры файлов комиксов



  - Реализовать FileParser интерфейс и базовую логику
  - Создать CbzParser для .cbz/.zip файлов (использовать Zip4j)
  - Создать CbrParser для .cbr/.rar файлов (использовать Junrar)
  - Создать PdfParser для .pdf файлов (использовать PdfiumAndroid)
  - Создать FolderParser для папок с изображениями
  - Добавить определение формата по расширению и magic bytes
  - _Requirements: 2.1, 3.1_

- [x] 4. Реализовать систему индексации библиотеки



  - Создать LibraryScanWorker для фонового сканирования через WorkManager
  - Реализовать FileIndexer для обхода директорий и поиска файлов
  - Создать MetadataExtractor для извлечения метаданных из файлов
  - Реализовать ScanProgress для отслеживания прогресса
  - Добавить восстановление индексации после перезапуска
  - Реализовать настройки включения форматов (Всегда/Условно/Никогда)
  - _Requirements: 2.2, 2.3, 2.5, 2.6_

- [x] 5. Создать систему кэширования обложек



  - Реализовать CoverExtractor для извлечения первой страницы как обложки
  - Создать CoverCacheManager с дисковым кэшем (Coil cache)
  - Добавить генерацию thumbnails с оптимальным размером
  - Реализовать очистку устаревших обложек
  - _Requirements: 2.4_

- [x] 6. Реализовать экран библиотеки



  - Создать LibraryScreen с Compose UI
  - Реализовать LibraryViewModel с управлением состоянием
  - Создать ComicGridView для отображения в виде сетки
  - Создать ComicListView для отображения в виде списка
  - Создать FolderView для отображения по папкам
  - Добавить переключение между режимами отображения
  - _Requirements: 1.1, 1.4_

- [x] 7. Добавить поиск и фильтрацию в библиотеке



  - Создать SearchBar компонент с анимацией сворачивания
  - Реализовать поиск в реальном времени с debouncing
  - Добавить фильтры по формату, папке, дате
  - Реализовать сортировку (по имени, дате, размеру)
  - Оптимизировать производительность поиска
  - _Requirements: 1.5, 1.6_

- [x] 8. Реализовать управление библиотекой







  - Добавить диалог выбора директории/файла через кнопку "+"
  - Реализовать добавление комиксов в библиотеку
