# Mr.Comic (Fresh Clone)

Hermes: when working in this repo, follow these rules.

## Project
- Comprehensive Android reader: comics, manga, webtoons, books, audiobooks
- Tech: **Kotlin, Jetpack Compose, Material 3, Hilt, Room, DataStore, Media3**
- Multi-module Gradle architecture (14+ modules)
- Features: OCR, translation, TTS, bookmarks, TOC, themes, typography controls

## Skills to Load
- `android-dev-patterns` — Kotlin/Compose/Hilt/Room/Coroutines
- `android-reader-qa` — reader flow testing, WebView, pagination, formats
- `systematic-debugging` — 4-phase root cause debugging
- `test-driven-development` — TDD RED-GREEN-REFACTOR
- `simplify-code` — parallel 3-agent cleanup
- `requesting-code-review` — pre-commit review + security
- `token-optimization` — minimize token usage

## Build & Run
```bash
./gradlew assembleDebug
./gradlew test
```

## Module Architecture
```
├── app/                    # Application entry point
├── core-model/             # Domain models
├── core-data/              # Data layer (Room, repositories)
├── core-domain/            # Use cases
├── core-ui/                # Shared UI components
├── engine-api/             # Reader engine API
├── engine-formats/         # Format-specific readers
├── engine-rendering/       # Rendering pipeline
├── engine-registry/        # Format registry
├── feature-reader/         # Reader feature module
├── feature-library/        # Library feature module
├── feature-settings/       # Settings feature module
├── feature-ocr/            # OCR feature module
├── feature-onboarding/     # Onboarding feature module
└── Translate/              # Translation module
```

## Code Style
- Kotlin idioms: `data class`, `sealed class`, extension functions
- Compose: state hoisting, `rememberSaveable`, Material 3 dynamic color
- Clean Architecture: domain layer has no Android dependencies
- Hilt: one module per feature/domain boundary
- Room: migrations tested, indices on query columns

## Testing
- Unit tests for reader logic, interaction policies, font catalog
- Format-specific tests (EPUB, FB2, text, archives)
- Use `@UninstallModules` + `@BindValue` for Hilt test overrides

## Pitfalls
- Experimental and legacy reader paths exist — check which is active
- Text vs raster container separation is in progress
- EPUB/HTML/DOCX formatting may have edge cases
- DJVU rendering is platform-dependent
- Check docs/ and QA checklists before major changes
