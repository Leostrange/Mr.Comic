# Gesture System Testing Guide

## Что было реализовано

Система жестов полностью интегрирована в ModernReaderScreen со следующими возможностями:

### 1. Зоны тапов (Tap Zones)
Экран разделен на 3 зоны:
- **Левая зона (25%)**: Предыдущая страница
- **Центральная зона (50%)**: Показать/скрыть UI
- **Правая зона (25%)**: Следующая страница

### 2. Двойной тап (Double Tap)
Циклическое масштабирование:
- **1-й двойной тап**: Fit to Width (по ширине)
- **2-й двойной тап**: Fit to Height (по высоте)
- **3-й двойной тап**: Fit to Screen (весь экран)
- **4-й двойной тап**: Возврат к Fit to Width

### 3. Долгий тап (Long Press)
- **Центр**: Показать верхнюю панель настроек
- **Слева**: Показать левую боковую панель
- **Справа**: Показать правую боковую панель

### 4. Pinch-to-Zoom
- Жест двумя пальцами для масштабирования
- Диапазон: 0.5x - 5x
- Плавная анимация

### 5. Индикатор страницы
- Показывается в правом нижнем углу при показе UI
- Отображает текущую страницу / всего страниц
- Кнопка Pin/Unpin для закрепления страницы

## Как тестировать

### Тест 1: Одиночный тап
1. Откройте комикс
2. Тапните по **центру** экрана → UI должен показаться/скрыться
3. Тапните **слева** (в первой четверти экрана) → Предыдущая страница
4. Тапните **справа** (в последней четверти экрана) → Следующая страница

### Тест 2: Двойной тап
1. Откройте комикс
2. Быстро тапните **дважды** по центру
3. Изображение должно масштабироваться по ширине
4. Тапните дважды снова → масштаб по высоте
5. Тапните дважды снова → масштаб по экрану
6. Тапните дважды снова → возврат к масштабу по ширине

### Тест 3: Долгий тап
1. Откройте комикс
2. **Удерживайте** палец на центре экрана ~0.5 секунды
3. Должна появиться верхняя панель
4. Удерживайте палец **слева** → левая панель
5. Удерживайте палец **справа** → правая панель

### Тест 4: Pinch-to-Zoom
1. Откройте комикс
2. Поместите два пальца на экран
3. **Разведите** пальцы → изображение увеличивается
4. **Сведите** пальцы → изображение уменьшается
5. При увеличении можно **панорамировать** (двигать) изображение

### Тест 5: Индикатор страницы
1. Откройте комикс
2. Тапните по центру → должен появиться индикатор "X / Y" в правом нижнем углу
3. Нажмите на иконку **булавки** → страница закрепляется (иконка меняет цвет)
4. Нажмите снова → открепляется

### Тест 6: Навигация свайпом
1. Откройте комикс
2. **Свайпните влево** → следующая страница
3. **Свайпните вправо** → предыдущая страница
4. Увеличьте страницу (pinch-to-zoom)
5. Свайпы должны быть **заблокированы** при увеличении (если blockSwipeWhenZoomed = true)

## Настройки жестов

Настройки хранятся в `ReaderUiState`:

```kotlin
data class ReaderUiState(
    // Gesture settings
    val gestureSensitivity: Float = 1.0f,        // 0.5 - 2.0
    val tapZoneLeftRatio: Float = 0.25f,         // 0.0 - 0.5
    val tapZoneRightRatio: Float = 0.25f,        // 0.0 - 0.5
    val tapZonesEnabled: Boolean = true,         // true/false
    val blockSwipeWhenZoomed: Boolean = true     // true/false
)
```

### Изменение чувствительности
- `gestureSensitivity = 0.5f` → менее чувствительно (дольше задержки)
- `gestureSensitivity = 1.0f` → нормально (по умолчанию)
- `gestureSensitivity = 2.0f` → более чувствительно (короче задержки)

### Изменение зон тапов
- `tapZoneLeftRatio = 0.3f` → левая зона 30% экрана
- `tapZoneRightRatio = 0.2f` → правая зона 20% экрана
- `tapZonesEnabled = false` → отключить зоны (весь экран = центр)

## Отладка

### Тестовый экран
Используйте `GestureTestScreen` для проверки жестов:

```kotlin
// В вашем Navigation или Activity
GestureTestScreen()
```

Этот экран показывает:
- Какой жест был обнаружен
- Счетчик жестов
- Визуальные зоны тапов (красная/зеленая/синяя)

### Логирование
Добавьте логи в `onGestureAction`:

```kotlin
onGestureAction = { action ->
    Log.d("Gesture", "Detected: $action")
    // ... handle action
}
```

## Известные проблемы

### Если жесты не работают:
1. **Проверьте интеграцию**: Убедитесь, что используется `ZoomableComicPage`, а не старый `ComicPage`
2. **Проверьте модификаторы**: `.readerGestures()` должен быть применен к Image, а не к Box
3. **Проверьте настройки**: `tapZonesEnabled = true` в `ReaderUiState`
4. **Используйте GestureTestScreen**: Протестируйте жесты на тестовом экране

### Если двойной тап не работает:
1. Проверьте скорость тапов (должно быть < 300ms между тапами)
2. Убедитесь, что тапы в одном месте (< 50px расстояние)
3. Попробуйте увеличить `gestureSensitivity` (например, 1.5f)
4. Проверьте, что нет конфликта с `onDoubleTap` в `detectTapGestures`

### Если долгий тап не работает:
1. Убедитесь, что удерживаете палец достаточно долго (~0.5 секунды)
2. Попробуйте уменьшить `gestureSensitivity` для более короткой задержки (например, 0.7f)
3. Не двигайте палец во время удержания

### Если pinch-to-zoom не работает:
1. Убедитесь, что используете два пальца
2. Проверьте, что `detectTransformGestures` не конфликтует с другими жестами
3. Попробуйте на реальном устройстве (эмулятор может не поддерживать мультитач)
