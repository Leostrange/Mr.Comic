# Reader runtime corpus

The corpus is deterministic and self-contained so instrumentation tests can run without host storage.

- `cbr-basic.cbr` was built with WinRAR from two Mr.Comic launcher PNGs using store mode. It contains no third-party comic content.
- `djvu-reference.djvu` is an unchanged test copy of the DJVU file supplied in `reference/formats`; SHA-256 is pinned in `manifest.json`.
- EPUB, DOCX, CBZ, text archive, PDF, and image-folder fixtures are generated by `TestBookBuilder`.
- TXT, HTML, and FB2 assets are small hand-authored fixtures whose checksums are pinned in `manifest.json`.

Do not replace an archive with a differently named ZIP: CBR and DJVU rows must remain real format samples.
