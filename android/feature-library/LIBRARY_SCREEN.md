# Документация по экрану библиотеки

## Обзор

Экран библиотеки предоставляет интерфейс для просмотра и управления коллекцией комиксов. Поддерживает три режима отображения: сетка, список и папки.

## Компоненты

### 1. LibraryUiState
**Расположение**: `LibraryUiState.kt`

Состояние экрана библиотеки:
- `comics` - список комиксов
- `folders` - список папок
- `viewMode` - режим отображения (GRID, LIST, FOLDER)
- `sortOrder` - порядок сортировки
- `isLoading` - индикатор загрузки
- `error` - сообщение об ошибке
- `selectedFolder` - выбранная папка
- `searchQuery` - поисковый запрос

### 2. LibraryViewModel
**Расположение**: `LibraryViewModel.kt`

ViewModel с бизнес-логикой:
- Загрузка комиксов и папок
- Сортировка и фильтрация
- Поиск комиксов
- Управление режимами отображения
- Предзагрузка обложек

### 3. Компоненты отображения

#### ComicGridItem
Карточка комикса для сетки:
- Обложка с placeholder
- Прогресс чтения
- Индикатор закладки
- Название с градиентом

#### ComicListItem
Элемент списка комиксов:
- Миниатюра обложки
- Название и метаданные
- Прогресс чтения
- Формат и количество страниц

#### ComicGridView
Сетка комиксов с LazyVerticalGrid

#### ComicListView
Список комиксов с LazyColumn

#### FolderView
Список папок с количеством комиксов

### 4. LibraryScreen
Главный экран с:
- TopAppBar с меню
- Переключение режимов отображения
- Сортировка
- FAB для добавления комиксов
- Обработка состояний (loading, error, empty)

## Использование

```kotlin
@Composable
fun MyApp() {
    LibraryScreen(
        onComicClick = { comicId ->
            // Открыть ридер
            navController.navigate("reader/$comicId")
        },
        onAddComicClick = {
            // Открыть диалог добавления
            navController.navigate("add_comic")
        }
    )
}
```

## Требования

✅ Требование 1.1: Главный экран библиотеки
