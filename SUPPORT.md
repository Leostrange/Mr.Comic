# Support

Вопросы по использованию Mr.Comic и предложения по функциям оформляйте через [GitHub Issues](https://github.com/Leostrange/Mr.Comic/issues). Перед созданием issue проверьте существующие задачи, укажите версию приложения, устройство/API level, формат книги и минимальные шаги воспроизведения.

Для translation, dictionaries, OCR overlay и AI-перевода используйте [issue #154](https://github.com/Leostrange/Mr.Comic/issues/154). Для проблем с безопасностью не используйте открытые issues — следуйте [SECURITY.md](SECURITY.md).

Запросы на коммерческое использование, перераспределение APK/исходников или альтернативное лицензирование направляйте владельцу репозитория в письменной форме. Такие действия не разрешены стандартной [Mr.Comic Source-Available License 1.0](LICENSE) без отдельного разрешения.
