# ✅ Исправление z-index панелей читалки

## 🐛 Проблема
Верхняя панель и боковая правая панель вызывались и находились **за изображением комикса**, что делало их невидимыми или недоступными для пользователя.

## 🔍 Анализ проблемы
Проблема была в неправильном порядке слоев в `Box` композиции:
1. **Основной контент** (изображение комикса)
2. **Scrim layer** (полупрозрачный фон)
3. **Панели** (TopSettingsPanel, PageListPanel, ThumbnailPanel)

Панели находились **после** scrim layer, что означало, что они отображались поверх scrim, но scrim перекрывал основной контент.

## 🔧 Исправления

### 1. Переупорядочивание слоев
**Было:**
```kotlin
// Основной контент
when (uiState.readingMode) { ... }

// Scrim layer
if (showTopPanel || showRightPanel || showThumbnailPanel) { ... }

// Панели
TopSettingsPanel(...)
PageListPanel(...)
ThumbnailPanel(...)
```

**Стало:**
```kotlin
// Основной контент
when (uiState.readingMode) { ... }

// Панели (поверх основного контента)
TopSettingsPanel(...)
PageListPanel(...)
ThumbnailPanel(...)

// Scrim layer (под панелями, но поверх основного контента)
if (showTopPanel || showRightPanel || showThumbnailPanel) { ... }
```

### 2. Добавление zIndex модификаторов
Добавлен `zIndex(10f)` для всех панелей, чтобы гарантировать их отображение поверх всех остальных элементов:

```kotlin
modifier = Modifier
    .align(Alignment.TopCenter)
    .zIndex(10f) // Высокий z-index для отображения поверх всего
```

### 3. Добавление импорта
Добавлен необходимый импорт для `zIndex`:
```kotlin
import androidx.compose.ui.zIndex
```
